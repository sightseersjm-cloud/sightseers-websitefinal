# Tent images

Add the three JELUCAMP tent photos here, named exactly:

- `tent-blue.jpg`
- `tent-orange.jpg`
- `tent-green.jpg`

They appear on the **Camping Tent Rental** page (Tours ▸ Camping Tent Rental),
in the Equipment section, each with a soft floating shadow. Referenced at
`/assets/tents/tent-*.jpg`. This folder is served statically by Vercel.

Until the files are added, the images hide themselves automatically (no
broken-image icons). Square-ish photos on a white/transparent background look
best with the floating shadow.
