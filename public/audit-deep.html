00 Deep-Dive Introduction

The v1 executive audit covers the required 23 deliverables at summary depth. Five findings in the first release were disproved by direct inspection of the source and have been corrected here and in the summary: alt text is complete across all 130 images; the $15 deposit and the 24-hour contact response time are both documented on the booking page; a GA4 loader and homepage JSON-LD both ship; and the admin passcode is scoped to an editor role that cannot reach bookings, messages, or accounts. 01 Standardized Service / Experience Page Template

Every tour, charter, villa, transfer, and virtual experience page should follow this structure. Consistency reduces cognitive load, standardizes analytics events, and makes future edits template-scoped instead of page-scoped.

01. Above-Fold Hero
Full-bleed image or 5-second video. Product name + one-line value promise. Starting price ("From $X per person") + duration. Primary CTA: "Book This" or "Request Quote". Secondary CTA: "Save to Favorites".
02. Fast Facts Row (Sticky on Scroll)
Duration · Group size · Difficulty · Ages · Language · Meeting point · Free cancellation window. All in one horizontal strip, icons + label.
03. Overview + Highlights
2–3 paragraphs. Then 4–6 highlight bullets with icons. What makes this specifically different from the generic version.
04. What's Included / Not Included (Two Columns)
Green checks vs. grey X. Zero ambiguity. Include transport, meals, drinks, tips, gear, insurance.
05. Itinerary Timeline
Hour-by-hour or stop-by-stop, collapsible. Photos per stop where possible.
06. Gallery (6–12 images + optional 360° / video)
Lazy-loaded, alt-tagged, first image below 200KB. Link to V-Tour preview where applicable.
07. Reviews (Minimum 3)
Star rating, reviewer name + origin, date, verified-booking badge. Rating widget must be schema.org/Review compatible.
08. Trust & Policy Strip
Cancellation policy summary · Weather guarantee · Safety certifications · Instant confirmation badge · Payment security badges.
09. Booking / Inquiry Panel (Sticky Right Column on Desktop)
Date picker · party size · add-ons · price summary · "Reserve for $15" primary button · "Ask a Planner" secondary. Recalculates in real time.
10. FAQ (5–8 Questions)
Accessible accordion. Include: age restrictions, mobility, what to bring, weather, refund window, group discounts.
11. Related Experiences (3 Cards)
Same destination or same audience. Keeps browse session alive if this page isn't a match.
12. Final CTA Repeat + Contact Alternatives
Book now · WhatsApp · Schedule a discovery call. All three visible for users who reached the bottom undecided.

1
Customer — Requests cancellation via account or contact form.
2
System — Checks cancellation window vs. published refund policy.
3
Staff — Approves refund amount; issues Stripe refund via admin.

System — Updates booking status; sends refund confirmation email.

Supplier Coordination

1
Staff — Marks booking as supplier-pending; sends supplier voucher (email/WhatsApp).
2
Supplier — Confirms via reply.
3
Staff — Marks supplier-confirmed; customer receives itinerary PDF.

V-Tour Session

1
Guide — Logs in via Guide Portal (Supabase Auth). Creates Mux live stream, receives RTMP ingest URL.
2
System — Session appears in Explorer with countdown.
3

Customer — Enters session with token → verify-token API returns HLS URL + Supabase chat channel.
5
Guide — Ends stream → session archived; Mux VOD asset created for replay.
6
System — Sends replay link + physical-tour upgrade offer to attendees.
